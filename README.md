# مِرآة

منصة "زبون سري" بالذكاء الاصطناعي للشركات: تتواصل مع الشركة كزبون حقيقي، وتقيس ردها، وتعطي صاحبها تقريراً بالدرجة والدليل، ثم تساعده على الإصلاح بمدرّب ووكيل رد يعملان بـ Claude.

## ما في المنصة

| الجزء | المسار | يعمل بدون إعداد؟ |
| --- | --- | --- |
| الصفحة الرئيسية والفحص المجاني (بموافقة المالك) | `/` | نعم |
| لوحة صاحب الشركة عبر رابط خاص سري | `/app/<رمز>` | نعم |
| التقرير القابل للمشاركة: الدرجة، الدليل، الاقتراح | `/r/<رمز>` | نعم |
| لوحة المشغّل: إرسال رسائل واتساب يدوياً وتسجيل الردود | `/ops` | نعم |
| لوحة الشركات للمشغّل: الخطط، الجدولة، المنافسون | `/dashboard` | نعم |
| عقول Claude: سيناريو، زبون، مقيّم، مدرّب، وكيل رد | `src/lib/ai` | محاكاة بدون مفتاح API |
| قناة البريد للزبون السري (إرسال واستقبال آلي) | `/api/inbound/email` | يحتاج Postmark |
| رسائل المالك: رابط اللوحة، التقرير جاهز، تحويل من الوكيل | `src/lib/notify.ts` | يحتاج Postmark |
| الفحص الأسبوعي وفحص المنافسين الشهري | Inngest cron | فوري يدوي بدون Inngest |
| الاشتراكات | `/api/billing/webhook` | يدوي بدون Lemon Squeezy |
| وكيل الرد على واتساب (النظام الكامل) | `/api/whatsapp` | تجربة داخل اللوحة فقط |
| الخصوصية والشروط (مسودات) | `/privacy` `/terms` | نعم |

**ما لا يُؤتمت عمداً:** رسائل الزبون السري على واتساب (يرسلها إنسان من جوال مخصص، لأن أتمتة واتساب العادي مخالفة لشروطه)، ونماذج المواقع (يملؤها المشغّل يدوياً لأن كل موقع مختلف).

## التشغيل محلياً

```bash
npm install
npm run demo     # بيانات تجريبية، ويطبع رابط لوحة مالك تجريبية
npm run dev      # http://localhost:3000
npm test         # 25 اختباراً
```

## الإعداد والنشر

الدليل الكامل خطوة بخطوة: [docs/SETUP.md](docs/SETUP.md). المتغيرات كلها في `.env.example`.

## البنية

- `src/lib/engine/scan.ts` دورة الفحص: إنشاء، رسائل، ردود، تقييم، درجة
- `src/lib/engine/dispatch.ts` الإرسال الآلي للقنوات المسموحة
- `src/lib/engine/schedule.ts` المنافسون والفحص الأسبوعي
- `src/lib/engine/agent.ts` وكيل الرد وواتساب
- `src/lib/engine/coach.ts` المدرّب
- `src/lib/ai/` كل استدعاءات Claude، والبرومبتات في `prompts.ts`
- `src/lib/scoring.ts` معايير التقييم وأوزانها
- `src/lib/db/` البيانات: ملف محلي أو Supabase (`supabase/migrations`)
- `CLAUDE.md` قواعد المشروع لـ Claude Code
